G1 · Search · Isolated concept

Stationary icon, expanding control

Click the magnifying glass. The 40px circular button stretches to the left into a connected search field while the icon and the adjacent toolbar buttons remain stationary. Results update as you type in Gallery. The Delete key icon clears the query without closing the bar; the magnifying glass or Escape closes it. The placeholder fades in gently but never delays typing.

This is a standalone interaction trial. Typing is supported, but no catalogue search is connected. The Watch History and Settings icons are deliberately nonfunctional in this preview.
No external dependencies · No Gallery application changes
