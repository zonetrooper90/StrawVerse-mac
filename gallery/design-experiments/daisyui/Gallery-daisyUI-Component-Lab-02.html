Implementation scope
The controls use the actual daisyUI 5.7.48 CSS. This starter edition can retrieve and embed it once, then save a completely offline HTML copy. The lab uses plain JavaScript for demo state—no React, no Tailwind JavaScript and no change to Gallery v103. The exported offline edition bundles its component and theme CSS; a future Gallery integration should also bundle only the approved CSS.
Design rule
Nothing here is a vote to replace the whole interface. We can select individual controls and agree on one or more custom themes after visual review. Gallery's existing Recently Watched animation, player controls, navigation logic and stored theme preferences remain untouched.
